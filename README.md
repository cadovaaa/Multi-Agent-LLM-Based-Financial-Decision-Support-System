# Multi-Agent-LLM-Based-Financial-Decision-Support-System

This project implements a graph-based multi-agent financial decision support system. The system answers stock and options trading queries by combining market data, technical indicators, options-chain signals, news sentiment, risk analysis, signal aggregation, decision generation, and reflection-based valuation.

The full runnable version is the "main.ipynb". And all the other .py files are extracted from the completed Colab notebook (also the "main.ipynb") and are included to make each team member's individual code contributions clear in the GitHub commit history.
